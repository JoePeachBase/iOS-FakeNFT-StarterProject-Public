# Эпик: Каталог

Декомпозиция эпика «Каталог» на три спринта в соответствии с ТЗ.

**Архитектурный паттерн:** MVVM  
**Фреймворк:** UIKit  
**Сеть:** URLSession через существующий `NetworkClient`  
**Многопоточность:** GCD (`DispatchQueue`, при необходимости `DispatchGroup`)   
**Хранилище настроек сортировки:** `UserDefaults`  

---

# Sprint 1 — Экран каталога коллекций

## Цель

Реализовать рабочий экран каталога, на котором пользователь может загрузить список NFT-коллекций, просматривать их, сортировать и перейти к выбранной коллекции.

## Пользовательская функциональность

* [ ] Пользователь может открыть каталог.
* [ ] Пользователь может просматривать список коллекций.
* [ ] Для коллекции отображаются обложка, название и количество NFT.
* [ ] Пользователь может выбрать способ сортировки.
* [ ] После изменения сортировки порядок коллекций обновляется.
* [ ] Выбранная сортировка сохраняется локально.
* [ ] После повторного запуска приложения сохраняется выбранная сортировка.
* [ ] Во время загрузки отображается индикатор загрузки.
* [ ] При нажатии на коллекцию открывается экран выбранной коллекции.

## Технические задачи

### Подготовка моделей и сетевого слоя каталога

| Задача                                                                      | Оценка |
| --------------------------------------------------------------------------- | -----: |
| Проанализировать API и существующую инфраструктуру проекта, определить необходимые модели и данные для экрана каталога | 1 ч 40 мин |
| Создать и адаптировать модели данных каталога | 1 ч |
| Реализовать сетевой слой каталога на основе `NetworkClient` и GCD | 2 ч |

### ViewModel каталога
| Задача                                                                      | Оценка |
| --------------------------------------------------------------------------- | -----: |
| Реализовать CatalogViewModel: загрузка данных, состояния экрана, сортировка и взаимодействие с View | 2 ч |

### View каталога

| Задача                                        | Оценка |
| --------------------------------------------- | -----: |
| Реализовать UI экрана каталога: ViewController, UITableView, ячейки, загрузка и отображение ошибок               | 2 ч |

| ------------------------------------------ | -----: |

# Sprint 3 — Избранное и корзина

## Цель

Добавить взаимодействие пользователя с NFT прямо на экране коллекции: управление избранным и корзиной.

## Пользовательская функциональность

* [ ] Пользователь может добавить NFT в избранное.
* [ ] Пользователь может удалить NFT из избранного.
* [ ] Пользователь может добавить NFT в корзину.
* [ ] Пользователь может удалить NFT из корзины.
* [ ] Состояние NFT в избранном отображается на экране коллекции.
* [ ] Состояние NFT в корзине отображается на экране коллекции.
* [ ] Для NFT, находящегося в корзине, отображается соответствующая иконка.
* [ ] После изменения состояния UI обновляется без повторного открытия экрана.
